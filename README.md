# Wordle

Wordle is a word-guessing game. The object of the game is to guess a 5-letter word in 6 tries.

[NYT Wordle](https://www.nytimes.com/games/wordle/index.html)
[Wordle.name clone](https://www.wordle.name/en/)

## Python

This implementation is built in Python at different levels to practice the language for beginners to more advanced coders.

### Level 1

In this version, players will have a basic check but there is no check for letter positions.
